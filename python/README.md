# Shared Python source

Shared Python utilities for VS Code Python tool extensions.

Install this directory from a pinned repository checkout. Its internal
distribution name, `vscode-python-tool-internal`, supports local
installation and wheel builds only; it is not a published product. The Python
import namespace remains `vscode_common_python_lsp`.

See the [main README](../README.md#consuming-in-extensions) for local-path
installation and bundling instructions.
